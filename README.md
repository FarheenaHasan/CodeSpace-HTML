# My First HTML Project

This is a beginner HTML and CSS project created as part of my CodeSpace learning journey.

## 📄 Project Description
This project contains a simple web page that includes:
- Basic HTML structure (`index.html`)
- Linked CSS file for styling (`style.css`)
- A heading and a paragraph centered on the page

## 🧠 What I Learned
- How to write a basic HTML document
- How to link a CSS file
- How to style elements using CSS

## 💻 How to Run
To view this project:
1. Download or clone the repository.
2. Open the `index.html` file in any web browser.
